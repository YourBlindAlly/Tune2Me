# Tune2Me

An accessibility-first iOS instrument tuner app, built for VoiceOver users from the ground up.

Three modes:
- **Reference Tone** — pick an instrument and string, hear a clean reference pitch.
- **Live Mic Pitch Detection** — real-time pitch feedback as you play, spoken aloud plus a full-screen color indicator for low-vision users.
- **Tune to Me** — the app plays a reference pitch, listens via the mic, and auto-advances through each string once you're in tune, guided end to end.
